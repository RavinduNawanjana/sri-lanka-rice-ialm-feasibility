# Field Images

Selected photographs document field monitoring infrastructure and crop development. They are drawn from the supplied 2025 project archive, renamed with neutral filenames, resized where needed, and re-encoded without the source EXIF metadata.

- `field_monitoring_chambers_2025_07_31.jpg`: paired chamber installations in vegetative-stage rice plots.
- `field_monitoring_chambers_2025_08_13.jpg`: field-wide view showing multiple chamber installations.
- `field_crop_maturity_2025_09_24.jpg`: later-season field view with chamber infrastructure in the background.

Photographs with clearly identifiable project personnel were not selected. A September image carrying “Zero Tillage” signage was also not included because that label conflicts with the final 32-row code structure and could misrepresent the analyzed L2 treatment.
