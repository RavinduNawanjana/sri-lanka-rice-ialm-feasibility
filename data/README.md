# Data

## `raw_public/`

Sanitized public reconstruction of the harvest-outcome source layout.

- `harvest_outcomes_source_layout.xlsx` preserves the source-style Excel structure for reproducible ingestion in R.
- `harvest_outcomes_source_layout.csv` contains the same `Harvest` values and is the input used by the continuously tested Python pipeline.
- Blank tillage/irrigation cells are intentional and reproduce the visually grouped source convention.

These files are reproducibility inputs, **not** copies of the institutional source-of-record.

## `derived/plot_outcomes_clean.csv`

Canonical public-safe form of the 32-row agronomic outcome workbook. It is regenerated by `analysis/python/step01_clean_harvest.py`. Values are retained as supplied; factor codes are parsed from `plot_code`; treatment labels remain conservative.

## `derived/plot_outcomes_long.csv`

Tidy long-form version of the 12 harvest outcome variables. Each row is one plot-outcome measurement with an explicit unit field.

## `derived/plot_outcomes_with_treatment_metadata.csv`

The clean plot table joined to the public nutrient-treatment metadata. This makes treatment-definition uncertainty explicit in the analysis-ready table rather than burying it in prose.

## `derived/growth_long_unlinked.csv`

Tidy long form of 32 growth workbooks. Each neutral series has 17 dates and five variables: Plant Height, Number of Tillers, Leaf Area Index, Leaf length, Leaf width. The series-to-treatment mapping is unresolved, so no plot/treatment code is assigned.

## `metadata/`

Treatment codebook, data dictionary, data-quality log, source register, and a schema for importing future GHG measurements.

## `reconciliation/`

Templates for the records that would most improve statistical validity: a final treatment-definition sheet and the plot/block/randomization/chamber/growth-series mapping.

Do not overwrite unresolved fields with guesses. New identifiers should be added only when backed by a contemporaneous project source.
